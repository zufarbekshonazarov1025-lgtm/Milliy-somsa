# Milliy somsa

Tandir somsa: zakaz, yetkazish, ombor, tan narx va qarzlar hisobi.

- `docs/` — dastur ekranlari (GitHub Pages orqali ochiladi)
- `android/` — telefon ilovasi (APK GitHub Actions orqali yig'iladi)
- Ma'lumotlar bazasi: Supabase ("Somsa" loyihasi), foydalanuvchilar `supabase/functions/foydalanuvchi` orqali qo'shiladi
